# 🎮 Unity 2D Game – LAB1_PRU213

Đây là project **Lab 1 môn PRU213** (Unity 2D).
Bài đã được chấm **9 điểm** ✅

Ai cần tham khảo hoặc học Unity cơ bản thì có thể clone về dùng.

## 📌 Giới thiệu

Project được xây dựng bằng **Unity 2D** nhằm thực hành các kiến thức:

* Scene & GameObject
* Sprite
* Collider & Rigidbody
* Script C#
* Player movement
* Basic game mechanics

## 🚀 Cách chạy project

### 1. Clone project

```bash
git clone https://github.com/DEVpowerLifter2004D/LAB1_PRU213.git
```

### 2. Mở bằng Unity Hub

* Mở Unity Hub
* Chọn **Open**
* Chọn thư mục project đã clone

### 3. Chạy game

* Mở scene trong thư mục:

```
Assets/Scenes
```

* Nhấn **Play**
